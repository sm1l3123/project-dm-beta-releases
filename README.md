# Project DM — Open Beta

Этот репозиторий содержит экспериментальные Windows-сборки **Project DM Open Beta** и файлы их автоматического обновления.

Open Beta предназначена для проверки функций до их принятия и слияния в стабильную ветку Project DM.

## Важно

- Open Beta может содержать незавершённые или экспериментальные функции.
- Beta-выпуск не считается стабильным релизом Project DM.
- Установщик Beta использует отдельное приложение **Project DM Beta** и отдельный канал обновлений.
- Рабочие данные сейчас находятся в общей папке `Documents\Project DM`, поэтому Stable и Beta не следует запускать одновременно.

Стабильные Windows-выпуски находятся отдельно: `sm1l3123/project-dm-releases`.

Исходный код Project DM остаётся в закрытом репозитории разработки.
